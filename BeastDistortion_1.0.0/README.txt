Beast Distortion v1.0.0
======================

Системные требования:
- Windows 10/11 (64-bit)
- Процессор: Intel Core i5 или эквивалент
- DAW с поддержкой VST3

Установка:
1. Скопируйте BeastDistortion.vst3 в папку:
   C:\Program Files\Common Files\VST3\
2. Перезапустите DAW
3. Выполните сканирование плагинов
